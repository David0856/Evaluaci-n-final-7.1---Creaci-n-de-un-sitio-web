LOS SABORES DE MI PATRIA D.M.J.
Evaluación Final 7.1 — Creación de un sitio web

Escenario seleccionado: Restaurante.

Descripción:
Este proyecto presenta un sitio web responsivo para un restaurante ficticio llamado
Los Sabores de Mi Patria D.M.J., inspirado en la gastronomía puertorriqueña.

Tecnologías:
- HTML5 con elementos semánticos.
- CSS3 personalizado.
- Bootstrap 5.3 para diseño responsivo.
- JavaScript para interacción, detalles, carrusel y validación de formularios.
- Imágenes SVG incluidas localmente.

Páginas:
1. Inicio
2. Menú
3. Historia
4. Especialidades
5. Reservas
6. Contacto
7. Galería
8. Bebidas
9. Postres
10. Eventos
11. Nuestro equipo
12. Políticas

Buenas prácticas:
- Estructura organizada por carpetas.
- Nombres descriptivos.
- Comentario en HTML sobre la estructura HTML5.
- JavaScript separado del HTML.
- CSS separado del HTML.
- Diseño adaptable a móvil, tableta y escritorio.
- Atributos alt en imágenes.
- Validación HTML y JavaScript en formularios.
